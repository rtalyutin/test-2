# Недетские сказки

Архив авторских сказок с финальными и альтернативными редакциями. Для каждой редакции доступен явный переключатель **Текст / Комикс**.

## Локальный запуск

```bash
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

## Timeweb Apps

Настройки приложения:

- репозиторий: `rtalyutin/test-2`;
- ветка: `main`;
- установка зависимостей: `npm ci`;
- команда сборки: `npm run build`;
- каталог публикации: `dist`;
- команда запуска для режима приложения: `npm start`;
- порт: переменная окружения `PORT` (Timeweb передаёт её автоматически).

В сборку входят все текущие сказки, альтернативные версии и комикс-режим.
